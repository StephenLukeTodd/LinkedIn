# powershell/

Windows PowerShell automation moved from the repository root into this folder for clarity.

Notable files:

- `Copy.ps1` — mirror/copy jobs with idempotent checks and cleanup.
- `MovementScript.ps1` — example file copy logger with placeholders for local paths.
- `Movephotos.ps1`, `SortPhotos.ps1` — photo/file organization helpers.
- `Moving_Anime.ps1` — CSV-driven folder consolidation for media.

Usage: open a `.ps1` file and adapt placeholder paths to your environment. These scripts show cross-platform automation experience.
